**Branch**: `main` | **Date**: 2026-06-08 | **Spec**: [spec.md](spec.md)

## Summary

Add a single `beginner?: boolean` flag to `CfopSolverOptions`. When true: F2L switches to a fluid priority loop + trigger table (mirroring the IntuitivePage tutorial), OLL splits into EOLL+OCLL, PLL splits into CPLL+EPLL — producing a 9-stage solution. All changes are contained within the six existing files in `packages/cubify/src/cfop/` plus the facade and tests — no new files introduced.

## Implementation Details

### 1. `CubeSolverCfop.ts` — Facade Options

Extend `CfopSolverOptions`:
```typescript
export interface CfopSolverOptions {
  timeoutMs?: number;
  /** Enables beginner mode: intuitive F2L + 2-look OLL/PLL. Default: false. */
  beginner?: boolean;
}
```

In `solve()`, pass the new field through the worker message:
```typescript
this._worker!.postMessage({ type: 'solve', patternStr, timeoutMs, beginner: options.beginner });
```

### 2. `cfop.worker.ts` — Stage Labels and Dispatch

Extend `SolveStageLabel`:
```typescript
export type SolveStageLabel = 'cross' | 'f2l-fr' | 'f2l-fl' | 'f2l-br' | 'f2l-bl'
  | 'oll' | 'oll-edges' | 'oll-corners'
  | 'pll' | 'pll-corners' | 'pll-edges';
```

Extend `WorkerInMessage`:
```typescript
| { type: 'solve'; patternStr: string; timeoutMs?: number; beginner?: boolean }
```

Add MASK entries for new labels:
```typescript
'oll-edges':   'oll-face-dim',   // same mask as oll — shows U-layer working area
'oll-corners': 'oll-face-dim',
'pll-corners': 'pll-face-dim',   // same mask as pll
'pll-edges':   'pll-face-dim',
```

Conditional dispatch in the solve handler:
- F2L: if `beginner`, call `solveF2lIntuitive(state)` → returns `Array<{label, alg}>` in fluid priority order; otherwise use existing `solveF2l()` with fixed order
- OLL: if `beginner`, call `solveTwoLookOll(state)` → returns `{eoll, ocll}`; push two stages with labels `'oll-edges'` and `'oll-corners'`
- PLL: if `beginner`, call `solveTwoLookPll(state)` → returns `{cpll, epll}`; push two stages with labels `'pll-corners'` and `'pll-edges'`

For intuitive F2L stage output: iterate the returned array (which is already in solve order) and build stages using `buildF2lMask(state, label)` capturing state before each alg is applied.

  { id: 'eoll-bar',     name: 'Bar',     alg: 'F R U R\' U\' F\'',                    eoPattern: [0,1,0,1] },

**CPLL_CASES and EPLL_CASES** — filtered subsets of existing PLL_CASES:

```typescript
// CPLL cases: corner-cycle algs. All three have ep == PLL_SOLVED_FINGERPRINT[4..7] in
// their canonical fingerprint, confirming they leave/start-with solved edges.
export const CPLL_CASES = PLL_CASES.filter(c =>
  c.fingerprint[4] === PLL_SOLVED_FINGERPRINT[0+4] &&  // ep == solved ep
  c.fingerprint[5] === PLL_SOLVED_FINGERPRINT[1+4] &&
  c.fingerprint[6] === PLL_SOLVED_FINGERPRINT[2+4] &&
  c.fingerprint[7] === PLL_SOLVED_FINGERPRINT[3+4]
);
// Result: [Aa-perm, Ab-perm, E-perm]

// EPLL cases: edge-cycle algs (Ua, Ub, H, Z). These are pll-1-* entries.
export const EPLL_CASES = PLL_CASES.filter(c => c.id.startsWith('pll-1-'));
// Result: [Ua, Ub, H, Z]
```

### 4. `OllSolver.ts` — 2-Look OLL

```typescript
export interface TwoLookOllResult {
  eoll: OllResult;   // reuses existing OllResult type
  ocll: OllResult;
}

export function solveTwoLookOll(state: RawState): TwoLookOllResult {
  // EOLL step: match eo[0..3] against EOLL_CASES with AUF
  const eoll = solveEoll(state);
  const afterEoll = eoll.alg ? applyAlg(state, eoll.alg) : state;

  // OCLL step: match co[0..3] against first 7 OLL_CASES (all have eo==0)
  const OCLL_CASES = OLL_CASES.filter(c =>
    c.fingerprint[4]===0 && c.fingerprint[5]===0 &&
    c.fingerprint[6]===0 && c.fingerprint[7]===0
  );
  const ocll = solveOcll(afterEoll, OCLL_CASES);

  return { eoll, ocll };
}
```

`solveEoll(state)`: checks if all edges oriented (skip); otherwise tries 4 AUF × 3 EOLL_CASES matching `state.edgeOrient[0..3]` against `eoPattern`.

`solveOcll(state, cases)`: same as `solveOll` but uses the 7-entry OCLL subset.

### 5. `PllSolver.ts` — 2-Look PLL

```typescript
export interface TwoLookPllResult {
  cpll: PllResult;   // reuses existing PllResult type
  epll: PllResult;
}

export function solveTwoLookPll(state: RawState): TwoLookPllResult {
  // CPLL: find alg that correctly positions all 4 corners (ignoring edges)
  const cpll = solveCpll(state);
  const afterCpll = cpll.alg ? applyAlg(state, cpll.alg) : state;

  // EPLL: corners solved; find alg that fixes edges
  const epll = solveEpll(afterCpll);

  return { cpll, epll };
}
```

`solveCpll(state)`: brute-force 4 AUF × 3 CPLL_CASES. For each combination, apply pre-AUF + alg, check if `cp[0..3]` matches solved corners under any post-AUF. Records `{ pre-AUF, case, post-AUF }`. 12 combinations max — trivially fast.

`solveEpll(state)`: brute-force 4 AUF × 4 EPLL_CASES. For each, apply pre-AUF + alg, call `isTopLayerAligned()`. 16 combinations max.

### 6. `F2lSolver.ts` — Intuitive F2L

```typescript
export function solveF2lIntuitive(
  state: RawState,
): Array<{ label: string; alg: string }>
```

**Priority loop:**

```typescript
const unsolved = new Set(['f2l-fr', 'f2l-fl', 'f2l-br', 'f2l-bl']);
const result: Array<{ label: string; alg: string }> = [];

while (unsolved.size > 0) {
  if (slotSolvedAll(s, unsolved)) break;  // cross+all solved guard

  // Pick the slot with the best tier
  let bestSlot: string | null = null;
  let bestTier = 5;
  for (const slot of unsolved) {
    if (slotSolved(s, slot) && crossOk(s)) {
      unsolved.delete(slot);  // already solved (maybe from a previous step)
      continue;
    }
    const tier = getPairTier(s, slot);
    if (tier < bestTier) { bestTier = tier; bestSlot = slot; }
  }
  if (!bestSlot) break;

  const alg = solveSlotIntuitive(s, bestSlot, [...unsolved].filter(x => x !== bestSlot && slotSolvedBefore(x)));
  if (alg) s = applyAlg(s, alg);
  result.push({ label: bestSlot, alg });
  unsolved.delete(bestSlot);
}
return result;
```

**`getPairTier(state, slot)`**: locates corner piece and edge piece for slot; returns tier 1–4 based on where they are.

**`solveSlotIntuitive(state, slot, mustSolve)`**: routes to appropriate handler:
- Tier 1 (Easy Insert): `applyEasyInsert(state, slot)` — U-turns to align above target slot, look up F2L_TRIGGERS
- Tier 2 (Setup Insert): `applySetupInsert(state, slot)` — three sub-cases:
  - White-side, colours match: R-tuck (R, U-turn, R'), then Easy Insert
  - White-side, colours don't match: similar tuck toward edge
  - White-up: park edge in back slot (U2 to target, R U' R' to push), then position corner, extract, Easy Insert
- Tier 3 (one stuck): `extractPiece(state, slot)` + recurse with updated state
- Tier 4 (both stuck): extract corner with R U R', then recurse

**Extraction from solved slots**: if a needed piece is stuck in a slot that is already in `mustSolve`, use a slot-safe extraction: do a U-turn to move it out of the front position, apply extraction, then re-solve that slot immediately afterward as a sub-step.

**Cancellation**: add `if (_cancelled) return []` guards at each while-loop iteration.

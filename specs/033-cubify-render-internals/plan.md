# Implementation Plan: Cubify Render Internals

**Branch**: `033-cubify-render-internals` | **Date**: 2026-05-13 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/033-cubify-render-internals/spec.md`

## Summary

Extends `CubeRenderer3D` with an `setInternals(enabled, options?)` method that: (1) makes coloured sticker panel materials semi-transparent, (2) renders the inward-facing plastic walls of cubelets as double-sided and semi-transparent to give a transparent-shell illusion, and (3) adds a stylised central core (sphere + 6 axis arms) anchored to the world origin that never participates in move animations. Theme changes while internals is active update all internals-related materials in the same render frame. A `CubeInternals.ts` helper isolates core geometry construction.

## Implementation Architecture

### Material mutation strategy (P1 — transparent stickers)

Each outward sticker slot already has its own `THREE.MeshBasicMaterial` or `THREE.MeshStandardMaterial` instance created by `_makeStickerMaterial()`. These are NOT shared — mutating their `opacity`/`transparent`/`depthWrite` properties when internals is enabled is safe and persists through `resetToSolved()` (which only updates `mat.map`, never creates new instances).

When internals is enabled:
```
mat.transparent = true
mat.opacity     = options.stickerOpacity
mat.depthWrite  = false
mat.needsUpdate = true
```

When internals is disabled:
```
const baseTransparent = this._theme.plasticOpacity < 1
mat.transparent = baseTransparent
mat.opacity     = 1.0
mat.depthWrite  = !baseTransparent
mat.needsUpdate = true
```

### Internal wall material strategy (P2 — visible walls)

Inward slots currently use the shared `this._plasticMaterial` instance. For internals mode, a dedicated `_internalsWallMaterial` is created (DoubleSide, transparent, wallOpacity, frame colour). When enabling, inward slots are reassigned to this material; when disabling, they're reassigned back to `_plasticMaterial`.

`DoubleSide` is required so the inside surfaces of cubelets are visible when viewed through transparent stickers from outside the cube.

### Core geometry sizing (P3)

Cube half-size = 1.5 units. Spec target: sphere ~15% of half-size.

| Component | Value |
|---|---|
| Sphere radius | 0.22 units (~15% of 1.5) |
| Arm cylinder radius | 0.08 units |
| Arm cylinder height | 0.80 units |
| Arm centre offset along axis | 0.62 units from origin (sphere edge + half-arm = 0.22 + 0.40) |
| 6 arms | ±X, ±Y, ±Z axes; CylinderGeometry rotated 90° to align with each |

The arms extend from ~0.22 (sphere surface) to ~1.02 (approaching center piece at 1.0). Total visual reach ≈ the center-piece position, matching the spec.

### setTheme() re-application

`setTheme()` conditionally recreates materials when `plasticChanged` or `materialTypeChanged`. After the final `restoreColours()` + `applyStickering()` calls at the end of `setTheme()`, if `_internalsEnabled`: call `_applyInternalsToMaterials()` to re-stamp opacity and update core/wall material colours.

### CubePlayer passthrough

`CubePlayer` has a `_renderer: CubeRenderer3D` private field. Expose `setInternals()` as a public passthrough method. The React wrapper (`CubePlayerHandle`) does not need this in the current feature scope — harness directly accesses `player.renderer` if needed.
